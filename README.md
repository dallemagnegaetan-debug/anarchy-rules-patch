# ANARCHY // RULES PATCH

## Version 0.2.1

La gestion des consommables de la version 0.2.0 a été **désactivée et retirée de l'archive**. Les consommables sont gérés directement comme des équipements ordinaires du compendium SRA2 (RR natives, durée et contrecoups dans la description ; fin d'effet manuelle).

Le module conserve uniquement la règle de non-cumul des armures principales. Il désactive les autres armures principales lors de l'activation d'une nouvelle armure. Il ne modifie pas les bonus des autres équipements.

Manifeste : `https://raw.githubusercontent.com/dallemagnegaetan-debug/anarchy-rules-patch/main/module.json`

Système ciblé : `sra2`, Foundry VTT 14.

La mise à jour ne supprime pas automatiquement les éventuels objets temporaires déjà créés dans les fiches par la v0.2.0. Les retirer manuellement si nécessaire.
